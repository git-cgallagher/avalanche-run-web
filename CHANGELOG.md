# Changelog

## 0.4.0 — 2026-10-28
- Cross-platform rewrite of the SpriteKit game (git-cgallagher/avalanche-run 0.3.0) in TypeScript with
  Canvas 2D and WebAudio, with the same gameplay, art, synthesized music and sound, creatures, prize boxes,
  combos, game speeds and high scores.
- Runs in the browser and as a Tauri desktop app: universal macOS DMG and Windows NSIS installer, built
  and published by GitHub Actions.
